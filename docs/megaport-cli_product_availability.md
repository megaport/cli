# availability

List the products your company can order and the markets for each

## Description

List the products your company can order and the markets for each.

This command looks up the company your API key belongs to. It prints one row for each product and market.

### Example Usage

```sh
  megaport-cli product availability
  megaport-cli product availability --output json
```

## Usage

```sh
megaport-cli product availability [flags]
```
